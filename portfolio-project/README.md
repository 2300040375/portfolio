# Guntaka Amrutha — Portfolio

A single-page personal portfolio site.

## Structure
- `index.html` — the entire site (HTML, CSS, and JS all in one file, includes your embedded photo)

## Run locally
Just open `index.html` in any browser, or in VS Code install the **Live Server** extension and click "Go Live" for an auto-refreshing preview.

## Deploy
Drag `index.html` onto https://app.netlify.com/drop for an instant live link, or push this folder to GitHub and enable GitHub Pages.
